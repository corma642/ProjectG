# Go Deliver! 개인정보처리방침 초안

시행일: 2026-07-22

Go Deliver!은 전 연령 사용자를 대상으로 하며, 이용자의 개인정보를 수집하거나 제3자에게 공유하지 않습니다.

## 수집 및 이용하는 정보

- 계정 생성이나 로그인을 요구하지 않습니다.
- 이름, 이메일 주소, 전화번호, 위치, 광고 식별자 등의 개인정보를 수집하지 않습니다.
- 광고, 분석, 사용자 추적 SDK를 사용하지 않습니다.
- 인앱 상품이나 유료 결제를 제공하지 않습니다.

## 기기에 저장되는 게임 데이터

게임 진행에 필요한 영수증 재화, 보유 캐릭터와 맵, 장착 상태, 최고 점수는 이용자의 기기에만 저장됩니다. 이 데이터는 개발자 서버나 외부 서비스로 전송되지 않습니다.

앱 데이터 삭제 또는 앱 제거 시 기기에 저장된 진행 데이터도 함께 삭제될 수 있습니다.

## 아동의 개인정보

Go Deliver!은 아동을 포함한 이용자의 개인정보를 의도적으로 수집하지 않습니다. 개인정보 수집 기능이나 맞춤형 광고를 제공하지 않습니다.

## 방침 변경

게임 기능 또는 데이터 처리 방식이 변경되면 이 문서를 갱신하고 시행일을 변경합니다.

## 문의

- 개발자: Go Deliver! 개발자
- 지원 이메일: `[Google Play에 등록할 지원 이메일 입력]`

> 게시 전 확인: 지원 이메일을 실제 주소로 교체하고, 이 문서를 공개 HTTPS 페이지에 게시한 뒤 게임 설정과 Google Play Console에 동일한 URL을 등록합니다.
